# Foundry Agent Workspace: release evidence matrix

This matrix maps the nine release acceptance criteria in [section 07 of the plan](foundry-agent-workspace-plan.html#acceptance) to the tests and source files that support them. The plan states that those criteria describe intent, not test results.

**Last checked: 23 October 2026, on `codex/audit-remediation-20261023`, starting from `main` at `ce73c53`.**
- `pnpm check --maxWorkers=1` passed: typecheck, lint, and 98 test files with 621 tests. All 22 Electron E2E tests passed.
- Locked native restore and Release build passed with zero warnings/errors; native tests passed with 8,181 successes and two environment-dependent skips (the policy-key CI scenario and a file symlink requiring Developer Mode/elevation).
- `pnpm package:dir` and `pnpm smoke:package` passed against isolated fixtures. The resulting executable is unsigned; actual installation, signing and live Azure qualification remain open. Detailed local evidence is described in [implementation status](implementation-status.md).

"Passed (offline)" means the cited automated tests pass with fake or injected providers. It does not mean the criterion has been shown against a live Azure Foundry deployment.

## Open gates

- **Live Foundry qualification.** Run a coding task on a verified deployment for each adapter, covering at least two model families (criterion 1).
- **Clean-profile Windows installation** of the release build (criterion 9).
- **Independent review of the release build**, with its findings retained (criterion 9).
- **Authenticode signing.** The installer and the portable executable are unsigned. `signing-and-distribution.md` describes a target Azure Trusted Signing setup, but no signing pipeline is configured.
- **Manual native checks** of the save dialog and toast delivery, plus a review of the distribution and license notices.
